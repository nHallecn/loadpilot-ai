# Impeccable UI review guidance

Source: [Impeccable](https://github.com/pbakaus/impeccable) and [Impeccable documentation](https://impeccable.style/docs).

Use this as a review checklist for LoadPilot:

- Do not default to nested rounded cards, repeated icon tiles, purple-blue gradients, or gray text on colored panels.
- Give each screen one clear visual idea. Remove copy and controls that do not help the next investigation action.
- Prefer one strong composition over a collection of generic dashboard widgets.
- Use typography, spacing, dividers, timelines, charts, and status signals to create hierarchy before adding containers.
- Use color with purpose: teal for healthy/connected, yellow for attention or measurement, and orange for caution or a suspected bottleneck.
- Review at narrow widths for overflow, cramped labels, and navigation failures.
- Check contrast, focus states, keyboard access, reduced motion, and readable text sizes.
- Review one region at a time, then run a whole-page audit for consistency and responsive behavior.

For LoadPilot, the primary composition is a visual investigation flow: target → baseline → evidence → diagnosis → follow-up.
